# 오디오 사양 — 픽셀 파도

코드: [`js/audio.js`](../js/audio.js) (`Sound` 객체)

## 1. 구조

| | 방식 | 파일 |
|---|---|---|
| **BGM** | mp3 스트리밍 + 크로스페이드(1.2초) | `assets/bgm/*.mp3` |
| **SE** | **WebAudio 실시간 합성** (칩튠 사각파 + 노이즈) | 없음 |

- **BGM 파일이 없으면 조용히 넘어갑니다** — 게임은 정상 동작(스프라이트 폴백과 같은 철학). 파일을 넣는 즉시 재생됩니다.
- SE는 파일이 필요 없습니다. 나중에 실제 녹음 SE로 바꾸려면 `Sound.sfx()`의 `switch` 분기만 교체하면 됩니다.
- 브라우저 자동재생 정책 때문에 **첫 입력(키/클릭/터치) 전에는 소리가 나지 않습니다.** `Input`이 첫 입력에서 `Sound.unlock()`을 호출합니다.

## 2. BGM 파일 목록

`assets/bgm/` 에 아래 이름 그대로 넣으면 자동으로 잡힙니다. **모두 선택 사항** — 있는 것만 재생됩니다.

| 파일명 | 쓰이는 곳 |
|---|---|
| `title.mp3` | 타이틀 화면 |
| `map.mp3` | 항해도 · 상점 |
| `stage1.mp3` ~ `stage7.mp3` | 각 해역 잡몹 구간 |
| `boss1.mp3` ~ `boss7.mp3` | 각 보스전 (보스 등장 시 자동 전환) |
| `ending.mp3` | 엔딩 시퀀스 |

해역 번호: 1 산호 초입 / 2 해파리 초원 / 3 거북이 고속도로 / 4 심해 협곡 / 5 난파선 묘지 / 6 폭풍 수면 / 7 용궁 앞바다

> 보스곡이 없으면 스테이지 곡이 그대로 이어집니다. `boss*.mp3`만 빼도 문제없습니다.

**권장**: mp3 128~160kbps, 2~3분, 루프 이음매가 자연스러운 구간. 파일당 2~3MB, 전부 넣으면 ~40MB.

## 3. 전환 규칙

`Game.syncBgm()`이 매 프레임 상태를 보고 필요할 때만 크로스페이드합니다.

```
타이틀 → title
항해도 → map
플레이 → stage{N}  (보스 등장 시 boss{N})
클리어 → 페이드 아웃 + 클리어 팡파레(SE)
엔딩   → ending
```

## 4. 효과음 목록 (합성)

| 이름 | 트리거 | 음색 |
|---|---|---|
| `shot` | 플레이어 발사 | 짧은 사각파 하강 블립 (아주 작게, 0.07초 스로틀) |
| `hit` | 적 피격 | 짧은 노이즈 틱 |
| `kill` / `killBig` | 적 격파 / 대물 격파 | 노이즈 버스트 + 하강음 |
| `pearl` / `pearlBig` | 진주 획득 / 큰 진주 | 삼각파 상승 블립 / 4음 아르페지오 |
| `powerup` | 파워 레벨 업 | 5음 상승 아르페지오 |
| `playerHit` | 피격(파워 다운) | 하강 사각파 + 노이즈 |
| `playerDown` | 격침 | 낮은 톱니파 하강 + 물속 노이즈 |
| `shield` | 진주 목걸이 방어 | 3음 밝은 아르페지오 |
| `sonar` | 소나 펄스(봄) | 저→고 스윕 + 노이즈 스윕 |
| `warn` | 보스 경고 | 2음 사이렌 4회 |
| `phase` | 보스 페이즈 돌파 | 5음 상승 |
| `bossDeath` | 보스 격파 | 노이즈 붕괴 + 6음 팡파레 |
| `clear` | 해역 클리어 | 7음 팡파레 |
| `ride` | 거북 택시 탑승 | 4음 상승 |
| `uiMove` / `uiSelect` / `buy` / `deny` | 메뉴 조작 | 짧은 블립 |

**폭주 방지**: 동시 발음 22개 제한 + 종류별 최소 간격(발사 0.07초, 피격 0.045초, 진주 0.035초). 탄막이 쏟아져도 소리가 뭉치지 않습니다.

## 5. 볼륨 · 음소거

- **항해도 우상단**의 `BGM` / `SE` 막대를 클릭하면 0 → 30 → 60 → 100% 순환
- **M 키**: 어느 화면에서든 음소거 토글
- 설정은 세이브(localStorage)에 저장됩니다

## 6. 믹싱 가이드 (BGM 제작 시)

효과음이 계속 겹치므로 BGM은 **중역을 비워두는 편**이 좋습니다. 기본 볼륨은 BGM 0.6 / SE 0.7로 잡혀 있어, BGM이 과하게 들리면 곡 자체를 -3dB 정도 낮춰 내보내는 편이 안전합니다.
