# 픽셀 파도: 집으로 가는 길 (가제) — 게임 기획서 v0.1

> 2026-08-26 초안 / 2026-08-27 갱신. 스테이지 1~7 + 엔딩 구현 완료 (Playable Alpha, 임시 아트).

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 횡스크롤 캐주얼 탄막 슈팅 (cute'em up) + 라이트 진행형 |
| 플랫폼 | 웹 (HTML5 Canvas / JS, 빌드 없음) |
| 한 줄 컨셉 | 태평양 한가운데서 조개폰 배터리가 3%. 인어는 지도도 없이 별빛 길을 따라 집까지 헤엄쳐 돌아간다. |
| 톤 | 픽셀 + 파스텔 바닷속 + 칩튠. 탄막인데 살벌하지 않고 반짝반짝. 죽어도 뽀글, 보스도 화해. |
| 세션 | 한 판(해역) **3~5분** (실측 기반 — 아래 10.1 참조) |

### 핵심 기둥
1. **탄막은 읽는 것** — 물속이라 탄이 느리고 오래 남는다. 반사신경이 아니라 길 읽기.
2. **여정 = 진행도** — 미니맵의 별빛 길이 한 칸씩 집까지 이어진다.
3. **죽어도 잃지 않는다** — 영구 진주는 안전. 파밍으로 구제, 실력으로 정복.
4. **예쁜 순간을 설계한다** — 보스 대파도 = 스크린샷 찍고 싶은 30초.

## 2. 물속 탄막 규칙 (차별점)

- **탄속 느림**: 물의 저항. 대신 탄이 오래 남고 밀도로 승부.
- **해류**: 스테이지별 흐름이 내 몸과 적탄을 민다. 같은 패턴도 해류에 따라 다른 탄막.
- **부력**: 정지 시 미세하게 떠오름.
- **탄막 미학**: 적탄 = 진주알·기포·플랑크톤. 위협이 아니라 반짝임.

## 3. 조작

**조작 체계는 하나, 입력 수단은 셋.** 마지막 입력 기준 자동 전환.

| 입력 | 이동 | 봄 |
|---|---|---|
| 키보드 | 방향키/WASD, Shift 저속 | Space |
| 마우스 | 포인터를 향해 최대속도로 유영 (가까울수록 자연 감속) | 클릭 / 화면 버튼 |
| 터치 | 손가락 추종 + **오프셋(캐릭터를 손가락 위 ~70px에 표시)** | 화면 버튼 |

- **속도 상한 통일**이 밸런스의 핵심: 포인터 추종도 순간이동이 아니라 "최대속도로 헤엄침". 탄막 패턴 한 벌로 모든 입력이 공정해진다.
- 샷은 **전 입력 공통 자동발사**.

## 4. 코어 루프 & 런 구조

1. 미니맵(태평양 항해도)에서 해역 선택 + 돌고래 1마리 선택
2. 스테이지 진행 → 적 처치 → 진주 드랍 → 파워업
3. 보스 격파 → 화해 연출 → 별빛 길 한 칸 연장 → 세이브 섬(상점)
4. 막히면 진주 파밍 → 영구 업그레이드 → 재도전

- **아케이드 원코인이 아니라 스테이지 단위.** 웹 유저의 5분 세션에 맞춤.
- 로그라이트 아님: **죽어도 영구 자산은 안 잃는다.**

## 5. 파워업 체계

### 5.1 판 안 (그 판 한정)

- **진주 = 만능 재화.** 적 처치 드랍, 자석 흡수(획득 스트레스 제로). 자석 범위 밖 진주는 **배경 스크롤과 같은 방향(왼쪽)으로 천천히 흘러감** — 인어가 앞으로 나아가고 있다는 관성 연출. 늦게 주우러 가면 뒤로 흘러가버리므로 가벼운 회수 긴장도 생김.
- **파워 게이지**: 진주로 참. Lv1→Lv3.
  - Lv1: 물결탄 1줄 / Lv2: 2줄 / Lv3: 3줄 부채꼴 + 후방 꼬리탄
  - **통상샷은 관통 없음** — 관통·범위·유도는 전부 돌고래의 영역. 통상샷이 만능이면 돌고래 선택이 죽는다.
- **피격**: 잔기 개념 없음. 샷 레벨 1 다운 + 진주 일부 튕김(3초 내 회수 가능).
- **격침**(Lv1에서 피격): 기포에 감싸여 수 초 후 그 자리 리스폰. 그 판 진주 30% 증발. **영구 진주는 무손실.**

### 5.2 판 밖 (세이브 섬 상점, 영구)

| 카테고리 | 예시 | 의도 |
|---|---|---|
| 몸 | 피격 허용 +1(진주 목걸이), 이속 +5% | 구제책 |
| 조개폰 | 배터리 최대 2→3칸, 시작 충전 +1 | 구제책 |
| 돌고래 | 해금/강화/고유기 (아래 6장) | **빌드의 몸통** |
| 꾸미기 | 지느러미 색, 헤어핀, 궤적 이펙트 | 파밍 배출구, 성능 무관 |

> **원칙: 기본샷의 순수 공격력은 팔지 않는다.** 기본샷 화력은 판 안 파워 게이지로만 오른다. 영구 성장은 **①생존 능력(몸·조개폰) ②돌고래 빌드** 두 갈래에만 존재한다 — 돌고래 강화는 피해량·연사·범위·고유기를 실제로 올리지만, 그건 "빌드 선택"이라는 별도 축이고 약점이 함께 설계돼 있다(6장). 파밍러도 탄막은 직접 피해야 하고, 실력자는 노업글 클리어의 재미.

### 5.3 조개폰 배터리 (봄) — 보스 격파로 해금되는 8종

- 기본 **소나 펄스**: **내 주변(반경 210)** 의 적탄만 진주로 변환 + 무적. 전 화면 소거가 아니다.
- **보스를 격파할 때마다 그 보스 컨셉의 강화 봄이 해금**되고, 항해도에서 돌고래처럼 하나를 골라 출격한다(B 키 / 슬롯 클릭).
- 충전: 보스 페이즈 돌파 시 +1. "아끼면 손해"의 긴장 유지.

> **설계 원칙: 강화 봄은 "더 센 소나"가 아니라 성격이 다른 선택지다.**
> 넓이 / 무적 / 화력 / 지속 / 기동 처럼 잘 듣는 상황이 달라야 고르는 재미가 생긴다.

| 봄 | 해금 | 효과 | 성격 |
|---|---|---|---|
| 소나 펄스 | 기본 | 주변 반경 210 탄 소거 | 기본 패닉 버튼 |
| 가시 폭발 | 팡팡 | 반경 260 소거 + 사방 12방향 관통 가시(피해 6) | 소거 + 화력 |
| 등불 정원 | 몽실 | 등불 3개를 놓아 0.5초 간격으로 반경 210씩 터뜨림 | **지속** — 예측해서 미리 깔기 |
| 특급 배송 | 씽씽 | 무적 돌진(0.55초) — 경로의 탄을 쓸고 적 격돌(10)·보스(25) | **기동** — 포위 탈출 |
| 초롱 유인 | 초롱 | 1.6초간 반경 420의 탄을 빨아들여 삼킴 → 자동 회수 진주 | **넓이 + 수급** |
| 유령화 | 부우 | 탄은 그대로, 4.5초 완전 무적 (탄막을 그냥 통과) | **생존** — 탄 밀도 최고 구간용 |
| 낙뢰 | 우르릉 | 반경 170 소거 + 전방 일직선 강타(피해 60) | **보스 화력** |
| 태풍의 눈 | 휘이 | **전 화면** 탄 소거 + 진주 전량 자동 회수 | 최종 보험 |

구현: [`js/bombs.js`](../js/bombs.js)의 `BOMB_DEFS` — 봄 하나 추가 = 항목 하나 추가. 지속형 효과는 `Game.updateBombs()`, 시각 효과는 `Game.drawBombFx()`.

## 6. 옵션: 돌고래 3종

클래식 3축 = 유도 / 확산·폭발 / 직선 관통. 약점을 일부러 남겨 스테이지별 선택이 의미를 갖게.

| | 🐬 파랑 — 유도 | 🎀 분홍 — 폭발 | ⚡ 은빛 — 관통 |
|---|---|---|---|
| 탄 | 음파 링, 적 추적 | 기포탄, 범위 폭발 | 초음파 직선 빔 |
| 강점 | 조준 불필요 → 회피 집중 | 잡몹 청소·화면 장악 | 보스·단단한 적 최고 DPS |
| 약점 | 단발 화력 최저 | 사거리 짧음 | 조준은 직접 |
| 성격 | 초보자용 | 진주 파밍용 | 숙련자·보스전용 |

- **Lv1 해금 → Lv2 강화 → Lv3 고유기** (유도: 피격 직전 0.3초 자동 슬로우 / 폭발: 폭발이 적탄 소거 / 관통: 차지 시 더블 파도)
- **유도 밸런스 규칙**: 유도탄은 **화면에 들어온 적만 조준** (화면 밖 스폰 지점 저격 금지) + 연사 느리게(0.9~1.0초). "조준 불필요"의 대가는 낮은 DPS — 이 규칙이 무너지면 유도가 유일해답이 된다.
- **보스 패턴 예고 "힌트!"는 종류 무관 공통 기능**(Lv1부터). 구제책을 특정 종에 묶으면 픽 왜곡 발생.
- 출격 화면에서 1마리 선택, 세이브 섬에서 교체. 3종 Lv3이 장기 파밍 목표.

## 7. 스테이지 구성 (여정 = 난이도 곡선)

1. **산호 초입** — 튜토리얼. 밝은 얕은 바다. (M2·S0 편중 = 평화)
2. **해파리 초원** — 등불 해파리. 세로축(D2·D3) 낙하 탄막.
3. **거북이 고속도로** — 거북 택시 탑승 강제 스크롤 + 가오리 편대전.
4. **심해 협곡** — 어둠 + 해파리 광원 기믹. 아귀 보스.
5. **난파선 묘지** — 유령 물고기, M6 붙박이 + 좁은 지형.
6. **폭풍 수면** — 상하 파도 지형 + 물속 번개.
7. **용궁 앞바다 → 집** — 최종. 라스보스는 "집에 못 가게 막는 것".

앨범아트 요소 매핑: 조개폰 배터리=봄 / 돌고래 힌트=옵션 / 거북 택시=탑승 구간 / 해파리 등불=심해 광원 / 세이브 섬=체크포인트·상점 / 미니맵=스테이지 셀렉트.

## 8. 잡몹 문법 — 5축 조합

**한 웨이브 = 이동(M) × 진입(D) × 편대(F) × 사격(S) × 개체스펙.** 부품을 조합해 웨이브를 만들고, 스테이지 아이덴티티는 **부품 편중**으로 만든다.

### M — 이동
| 코드 | 패턴 |
|---|---|
| M1 | 직진 통과 |
| M2 | 사인파 통과 (진폭·주기가 변주 파라미터) |
| M3 | 정지–사격–이탈 |
| M4 | 유턴 (뒤통수 교육) |
| M5 | 완만 추적 (급선회 금지) |
| M6 | 붙박이 포대 (지형 고정, 스크롤 따라 흘러옴) |
| M7 | 해류 편승 |

### D — 진입 방향
D1 우→좌(기본) / D2 상→하 낙하 / D3 하→상 부상 / D4 대각 / D5 좌→우(등 뒤, 후방탄의 존재 이유)

### F — 편대
F1 단기 / F2 종대(뱀, 궤적 복사) / F3 V자 / F4 벽(틈 1개) / F5 링(조여옴, 후반) / F6 시차 웨이브(0.5초 간격 반복)

### S — 사격
S0 무발사(리듬의 쉼표) / S1 조준 단발 / S2 전방위 소량 / S3 낙하탄(폭격기형) / S4 설치(기포 기뢰) / S5 유언탄(근접격파 교육)

### 스펙
HP: 기본 2발 / 단단(4~7발, 관통 돌고래의 존재 이유) / **대물** · 속도 3단 · 크기 3단

### 대물 (big) — 미니보스급 탱커
크고 튼튼한 심통 그루퍼 (hp 32~48, 스테이지 갈수록 상승 — Lv2 화력 기준 3~4초 집중 사격). S2 링 살포(ringN 10~14발). **M3(정지-살포-이탈)** 또는 **M2(저속 횡단)**로 스테이지당 2회 배치 — 잡몹 구간의 미니 이벤트. 무시하고 피할 수도 있지만 **격파 시 큰 진주 확정 드랍**("대물 사냥 성공!") — 리스크/리턴 선택지. 관통 돌고래·소나의 좋은 표적.

### 공통 규칙
1. **편대 전멸 보너스**: F2~F6를 한 마리도 안 놓치면 큰 진주 드랍. 파밍 동기 + "다 잡을까 피할까" 선택.
2. **웨이브는 데이터로**: `{ enemy, M, D, F, S, n, interval, hp, ... }` JSON 타임라인. 밸런스 조정 = 편집. 스테이지 추가 비용 최소화.
3. **리듬 원칙 (루즈함 방지)**: 웨이브 간격 2.5~4초, 대부분의 웨이브에 0.5~1.5초 시차 부속 웨이브를 겹침 — "사격 레인 + 진주 셔틀 레인"이 동시에 흐르는 그림이 기본형. 빈 화면은 막 전환 쉼표에만 의도적으로 허용. 목표 지표: 잡몹 구간 화면 위 평균 8~12마리, 빈 화면 5% 미만.

## 9. 보스 설계

### 9.1 공통 템플릿
> **대파도(大波濤)** = 보스 클라이맥스 탄막을 부르는 내부 설계 용어. **화면에는 패턴 이름을 표시하지 않는다** — 이름 호명 연출 자체가 특정 게임(동방)의 고유 문법이라, 페이즈 전환은 **보스 대사 한마디**로만 연출한다. 단, 패턴마다 내부 id·이름은 데이터로 유지 → 격파한 보스의 개별 패턴을 고난도로 재도전하는 **챌린지 모드**의 기반.

조준탄 교육 → 복합 문형 → **규칙 있는 대파도**(화려하지만 발견하면 쉬움) → 화해 연출 → **타임아웃 자비**(오래 끌면 밀도 감소). 체력바 = 진주 목걸이. 격침당해도 보스 체력·페이즈 유지(리셋 없음). 격파한 보스는 미니맵 친구 등록 + 재방문 시 인사.

> **방사형 패턴의 거리 이점 금지**: 보스 중심에서 퍼지는 탄(나선·확산)은 멀수록 각도 틈이 벌어져 원거리 캠핑이 정답이 된다. 방사형 대파도에는 반드시 원거리 처벌을 짝지을 것 — 조준탄 인터리브(팡팡: 나선+주기 조준 부채꼴) 또는 전역 균일 생성(초롱: 별이 화면 전역에서 태어남, 0.7초 무해 반짝 예고 후 활성·플레이어 반경 110px 금지).

### 9.5b 스테이지 4 "심해 협곡" 문법 편중 — 어둠 시스템

- **어둠 오버레이(dark 0.8)**: 광원 근처만 밝음. 광원 = 플레이어 주변(r175)·등불 해파리(r185)·기뢰·별탄·보스 초롱.
- **공정성 규칙: 적탄은 어둠 위에 항상 희미하게(50%) 재드로** — 안 보여서 맞는 건 금지. 아군 샷도 35%로 재드로.
- **시그니처 선택**: 등불 해파리가 이 스테이지에선 S0 광원 운반자. 잡으면 진주, 살려두면 시야.
- **M5(완만 추적) 데뷔**: 독니고기(viper, hp3) — 어둠 속에서 형광 눈만 번뜩이며 다가옴. 9초 후 추적 포기.
- 구현: 어둠은 오프스크린 캔버스 + destination-out 광원 구멍(캐시된 글로우 스프라이트). 스테이지 레지스트리의 `dark` 필드 하나로 온오프.

### 9.5d 스테이지 5 "난파선 묘지" 문법 편중 — 지형 시스템

- **wreck(지형 장애물)**: 위/아래에서 선체 잔해 기둥이 흘러와 통로를 좁힘(`frac`으로 높이 조절). 불괴·샷 통과·접촉 피격. 상하 동시 = 좁은 통로, 연속 배치 = 지그재그. 전경 패럴랙스 속도(95~105)로 흘러옴.
- **유령 물고기(ghost)**: 실체(1.6초) ↔ 반투명(0.8초) 사이클. 반투명 중엔 샷 통과·접촉 무해·표적 제외 — **깜빡임 리듬을 읽고 실체일 때 잡는다.**
- **D4(대각 진입)·F5(포위 링) 데뷔**: 유령이 대각으로 스며들고, 플레이어를 중심으로 사방에서 조여옴.
- 배경: 탁한 청록 + 옅은 어둠(dark 0.3, 광원 시스템 재사용).

### 9.5f 스테이지 6 "폭풍 수면" 문법 편중 — 해류·번개 시스템

- **스테이지 해류(storm)**: 진동하는 흐름(±70px/s, 수직 ±26)이 **플레이어·적탄(0.75배)·M7 잡몹(1.4배)**을 밀고 당김. 탄막이 휘는 게 스펙터클. HUD 상단에 해류 방향·세기 화살표(가독성 필수).
- **M7(해류 편승) 데뷔**: 서핑 물고기 — 흐름 따라 가감속. **이로써 잡몹 문법 5축 전 부품 구현 완료.**
- **물속 번개**: `{ t, bolt: x비율 }` 한 줄 = 예고 기둥(0.9초, 깜빡 점선) → 낙뢰(0.4초, 화면 번쩍+흔들림). 단발 → 2연속 → 스윕(시차 예고로 파도치듯) 순으로 에스컬레이션. 보스도 같은 시스템 사용.

- 격파: 소용돌이가 풀리며 → "...눈 속은, 이렇게 조용했구나." → "...집, 데려다줄게. 같이 가." → **엔딩 시퀀스**.

### 9.5h 스테이지 7 "용궁 앞바다" — 최종 시험 & 엔딩

- **전 부품 총출동**: 여정에서 배운 모든 문법이 한 번씩 돌아온다 (교행·기뢰·유령 포위·좁은 통로·독니 추적·번개 스윕·유턴 유언탄·대물 2회). 약한 폭풍 잔재(storm 0.55). 여명빛 팔레트.
- **엔딩**: 라스보스 격파 → 폭풍이 걷힌 여명 바다 — 무지개가 용궁에 내려앉고, 별빛 길이 완성되고, 인어 뒤로 **일곱 친구가 줄지어 귀향 행진**(팡팡·몽실·씽씽·초롱·부우·우르릉·휘이). 텍스트 시퀀스("폭풍이 걷혔다 → 다녀왔습니다! → 여정의 기록") 후 항해도로.

### 9.6 스테이지 3 "거북이 고속도로" 문법 편중

- **속도의 스테이지**: 전 웨이브 고속(spd 150~240). 가오리 M3 V편대전 중심.
- **D5(등 뒤 추월) 데뷔**: 왼쪽에서 진입. 무해 버전으로 교육 후 S1 조합(후방 꼬리탄 Lv3의 시간). 양방향 교행 컷이 스테이지 시그니처.
- **M4(유턴)·S5(유언탄) 데뷔**: 뒤통수 교육 + 근접 격파 조심 교육.
- **거북 택시 탑승 구간(ride)**: 스테이지 중간 ~22초. 등껍질 무적(황금 아우라) + 5배 스크롤 + 스피드 라인 + 사인 진주 트레일·진주 링 + 무발사 사냥감. 탑승 순간 화면 적탄 전부 진주 변환. 순수 보너스 타임 — 긴장 곡선의 큰 쉼표.
- 배경: 쨍한 청록 팔레트.

## 9.9 난이도 체계

**설계 원칙: 현재 밸런스 = 이지. 타임라인·보스 코드는 한 벌 유지, 난이도는 곱셈 모디파이어.**
상위 난이도 = ①잡몹 탄 밀도 상향 ②보스 기존 패턴 강화 + 체력 상향 ③**추가된 체력분만큼 신규 패턴**.

| 모디파이어 | 이지 | 노멀 | 하드 |
|---|---|---|---|
| 잡몹 발사 간격 (fireInt) | ×1 | ×0.68 | ×0.48 |
| 적탄 속도 | ×1 | ×1.1 | ×1.22 |
| 링 탄수 (S2: 포대·대물) | +0 | +2 | +4 |
| 기뢰 타이머 | ×1 | ×0.85 | ×0.7 |
| 보스 패턴 간격 (mercy() 훅에 일괄) | **×0.85** | ×0.6 | ×0.47 |
| 보스 체력 | ×1 | ×1.25 | ×1.55 |
| **대물 체력** | ×1 | ×1.3 | ×1.6 |
| 진주 보상 | ×1 | ×1.3 | ×1.6 |

**사격 패턴 진화** — 배율을 넘어 난이도마다 패턴 자체가 변한다 (Enemy.shoot):

| S축 | 이지 | 노멀 | 하드 |
|---|---|---|---|
| S1 조준 | 1발 | 2발 부채꼴 | 3발 부채꼴 |
| S2 전방위 (포대·대물) | 링 | 링+2 + **노리는 조준탄 동반** | 링+4 + 조준탄 + **무작위 흩뿌리기 3발** |
| S3 낙하 (해파리) | 1발 똑 | **V자 2발** | **부채꼴 3발 흩뿌림** |
| S4 기뢰 폭발 | 링 6발 | 7발 | 8발 |
| S5 유언탄 | 조준 1발 | 조준 2발 | **5방향 흩뿌림** |

**보스 탄수 상향** — 2단 구조:
1. **공용 헬퍼** (`bossAimed`/`bossRing`, 전 보스 자동): 조준 부채꼴 +1/+2발, 링 +3/+6발, **탄속 기본 +12%(전 난이도)**. 단발 조준도 노멀부터 부채꼴화.
2. **시그니처 밀도 개별 상향**: 팡팡 나선 하드 5줄기 / 몽실 커튼·정원 +1/+2 & 하드 기뢰 3개 / 씽씽 콘보이 +1/+2칸·하드 트래픽 2차선 동시 / 초롱 별밤 +10/+20 / 부우 포위 유령불 +2/+4 / 우르릉 낙뢰 스윕 +1/+2발 / 휘이 하드 나선 4줄기·폭풍 +8/+16. 벽·커튼류의 **틈 폭(2칸)은 전 난이도 유지** — 밀도는 올라도 길은 있어야 한다.

- **해금: 해역별** — 그 해역을 이지 클리어 → 노멀 해금, 노멀 클리어 → 하드 해금. 항해도 별 색 = 최고 클리어 난이도(청록/금/빨강).
- 조작: 항해도에서 난이도 칩 클릭 또는 ↑↓. 타임아웃 자비는 전 난이도 유지.
### 진(眞) 대파도 — 하드 전용 4페이즈

체력 18% 이하(하드에서만)에 발동하는 숨은 최종 페이즈. **설계 원칙: P3에서 배운 규칙을 한 겹 비튼다** — 익힌 규칙이 배신당하는 순간이 진짜 클라이맥스. 발동 시 각성 대사 + 배터리/진주 보상. `BOSS*_PATTERNS`의 4번 슬롯(챌린지 모드 연결).

| 보스 | 진 대파도 (내부명) | 비틀기 |
|---|---|---|
| 팡팡 | 진·뾰족뾰족 온천기포 (`pangpang-true-spa`) | 정회전 3 + **역회전 3 나선 교차** — 안전지대가 여닫힘 |
