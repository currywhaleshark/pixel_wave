# bgm

Suno 등으로 만든 BGM을 여기에 넣습니다.

```
title.mp3                 타이틀
map.mp3                   항해도 · 상점
stage1.mp3 ~ stage7.mp3   각 해역
boss1.mp3 ~ boss7.mp3     각 보스전 (선택)
ending.mp3                엔딩
```

전부 선택 사항입니다 — 있는 파일만 재생되고, 없으면 조용히 넘어갑니다.
자세한 규격: [`docs/AUDIO_SPEC.md`](../../docs/AUDIO_SPEC.md)
